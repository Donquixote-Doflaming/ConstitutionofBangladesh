বাংলাদেশের সংবিধান (Constitution of Bangladesh) — Interactive Explorer & Study App

An interactive, single-file web application designed for reading, searching, and studying the Constitution of the People's Republic of Bangladesh (গণপ্রজাতন্ত্রী বাংলাদেশের সংবিধান) in plain, accessible Bengali.

🌐 Live Demo: https://donquixote-doflaming.github.io/ConstitutionofBangladesh/

✨ Key Features

Complete Article Explorer (অনুচ্ছেদ ১ — ১৫৩):

Covers all 11 Parts (ভাগ) and 153+ Articles (including sub-articles like ২ক, ৪ক, ৭ক, ৭খ, ১৪১ক and repealed articles).

Plain-language Bengali summaries and structured bullet breakdowns for easy reading and exam preparation (BCS, Bank, University Admission, Law).

Smart Bilingual Search & Filtering:

Search instantly by Bengali or English article numbers (e.g., typing 26 or 7a automatically matches ২৬ and ৭ক).

Filter by keyword, title, or specific Constitutional Part (১ম — ১১শ ভাগ).

Toggle between compact cards and expanded details (সকল বিস্তারিত দেখুন).

Dual Theme Support:

Soft Study Theme (Default): Warm paper background with sage green, soft blue, and amber accents optimized for long reading sessions.

Classic Dark Theme: High-contrast dark interface with cyber-yellow and cyan highlights.

Theme preference is saved automatically in localStorage.

Zero-Dependency Single-File Architecture:

Built purely with vanilla HTML, CSS, and JavaScript—no build tools, bundlers, or backend required.

🚀 Getting Started

Run Locally

Clone the repository:

git clone https://github.com/donquixote-doflaming/ConstitutionofBangladesh.git


Navigate into the project directory:

cd ConstitutionofBangladesh


Open index.html directly in any modern web browser (Chrome, Firefox, Edge, Safari).

Deploy on GitHub Pages

Push this repository to GitHub.

Go to Settings → Pages.

Under Build and deployment, select Deploy from a branch, choose main (root /), and click Save.

Your app will be live at https://donquixote-doflaming.github.io/ConstitutionofBangladesh/.
